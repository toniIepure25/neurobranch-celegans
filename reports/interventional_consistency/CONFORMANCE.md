## Detail

### nc-mcm — `not_reproduced`

The official NC-MCM implementation is Julia and no Julia executable is present, so its 15 source files cannot run here. 16 precomputed model archives exist and are loadable, but a precomputed embedding is an output, not the method: it cannot establish that a re-implementation is conformant.

### bundlenet-v5 — `not_reproduced`

BunDLe-Net v5 is a preprint with no executed reference here; the identifier was verified at Crossref, but no conformance run is claimed.

### enumerating-reference — `simulated`

The oracle is an exact enumeration over synthetic kernels. It is ground truth for the benchmark, not evidence about any biological system; it agreed with the independent sampling estimator on 4 fixtures.

### identifiability-witness — `unidentifiable`

Under the witness operator the error does not shrink with the observation window, because the operator's effect depends on a context that never enters the observation. The correct report is not_identified, not a small error.
