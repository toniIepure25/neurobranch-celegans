# Baseline fidelity audit

- **Tabular conditional-response predictor.** Fit the single probe response vector by smoothed frequency for each permitted feature tuple. The fixed action is understood from setup. A genuine predictive state requires a sufficient panel of predictions of future action-observation tests and a state update rule. The table implements a one-query prediction, so this study reports a matched direct comparator and no PSR results. The earlier draft's “tabular predictive state” label is superseded. [Littman, Sutton and Singh](https://proceedings.neurips.cc/paper_files/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf)
- **Full-history oracle and compressed-state oracle.** The evaluator uses the true latent state space, initial and transition kernels, deterministic observation and sensor kernels, exact intervention kernel, response mapping and balanced mechanism prior to construct exact model beliefs over compatible checkpoint states. The decision rule sees only its corresponding information cell at inference. It uses the supplied model and TV-optimal action rather than any held-out latent label input. Mechanism labels separately determine ground-truth rows for the scorer. Classical POMDP belief states give a sufficient statistic for model-based inference. [Kaelbling, Littman and Cassandra](https://doi.org/10.1016/S0004-3702%2898%2900023-X)
- **Distributional evaluation.** TV compares a categorical forecast to a true categorical distribution. Expected TV to one-hot outcomes rewards concentration on a mode. Proper outcome-based scores would be suitable for a separate diagnostic with realized outcomes. The frozen primary evaluation uses exact truth and requires no realized score outcome. [Gneiting and Raftery](https://doi.org/10.1198/016214506000001437)
