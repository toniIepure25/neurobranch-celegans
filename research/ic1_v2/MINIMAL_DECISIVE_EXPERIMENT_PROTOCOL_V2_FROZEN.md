# Minimal decisive experiment, frozen protocol v2.0

Scientific question. Under a fixed pre-intervention observation contract, how much distributional intervention-response error is unavoidable, how much changes when the first position is discarded, and how much comes from learning with finite data? The one added measurement is a fixed positive information control.

## Probability model

Mechanism M is an independently drawn binary context C per episode, with prior (1/2, 1/2). The adversarial mechanism class for the separately reported minimax reference is {M₀,M₁}, where M_c holds C=c throughout that episode. Start with position uniform on {0,1,2} and independent velocity uniform on {−1,+1}. At each step, velocity is retained with probability 17/20 and reversed with probability 3/20. The one passive step adds updated velocity modulo three. The checkpoint state X is (current physical position P, current velocity V, context C). Each of its twelve states has joint mass 1/12. The full permitted history H is the ordered pair of positions across the passive step. Compression Z retains only the second position.

The sensor S reads C exactly at the checkpoint, costs one read and changes no dynamics. At the only target intervention a*, update velocity, then add that velocity and the context modulo three. The one external response Y is the final physical position. The exact categorical law Q_m at the reference history is conditional on the full checkpoint (P,V,C). Under compressed inputs the evaluator still scores against those original rows, so that averaging over aliased starts measures information loss. The truth target is constant across information conditions.

For a fixed predictor f, define R_c(f) = E[TV(f(I), Q_c) | M_c], averaging the history and available sensor within that mechanism. TV(q,Q) = Σ_y |q_y−Q_y|/2. Equal-prior Bayes risk is (R₀(f)+R₁(f))/2. Worst-fixed-mechanism risk is max(R₀(f),R₁(f)), taking the maximum after the within-mechanism expectation. Oracle risks take the infimum over all categorical tables on the permitted input I. The validated exact optima are 17/40 for full/base, 17/40 for compressed/base, 0 for full/sensor and 7/20 for compressed/sensor, in both decision criteria under their separate definitions. The identity of these values follows from the derivations, not an exchange of expectation and maximum. [Exact risks and decomposition](RISK_DEFINITIONS_AND_ORACLE_DERIVATIONS.md)

## Learning and primary estimand

The single rule is a supervised tabular conditional-response predictor with fixed pseudocount 0.5 per category. Training uses one observed a* response per episode. Predictor inputs are H or Z, and S in the two sensor conditions. Development uses independent episodes from the same declared model. The privileged exact belief-state oracle uses the true model and permitted inputs to determine the best TV action. It is an analytical reference. [Information contract](INFORMATION_AND_LEAKAGE_CONTRACT.md) · [Baseline fidelity](BASELINE_FIDELITY_AUDIT.md)

The primary estimand is the expected paired difference in equal-prior Bayes TV risk of the two predictors fitted on 768 training episodes, compressed/sensor minus full/sensor. The expectation includes independent training draws. Within each block, score both predictions against the exact categorical response law on the same 512 independently generated passive checkpoints and average the differences. Score episodes yield no realized Y. Average these differences over 200 independent blocks. The other training sizes, both base conditions, exact enumerated fitted risks, mechanism-specific risks, support and the decomposition are secondary. Keep the maximum over mechanism expectations separate from the Bayes primary. The IC1-v2 support diameter and occupancy-weighted pair discrepancy remain distinct instrument diagnostics.

Use the predeclared two-sided marginal 95% Student t interval for the mean of the 200 paired block differences. Blocks are the independent units for this interval. Nested training sizes and paired conditions within blocks are dependent. The oracle compression difference is 7/20, and the fixed scientific agreement margin is 1/20 TV, about one seventh of that constructed effect. Report within, below or above the reference band [0.30,0.40] only if the whole interval falls within or is entirely outside on the indicated side. Any overlap without full containment is inconclusive for agreement. Secondary comparisons are descriptive. No gate requires a favorable ranking.

Use the plans, engine and seed tree in the three machine-readable files linked below. Uniform sampling is IID with context unbalanced by chance, without fixed stratum quotas.
