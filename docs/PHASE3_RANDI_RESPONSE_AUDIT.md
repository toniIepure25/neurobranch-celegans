# Phase 3 Randi response audit

**Dataset:** Randi et al. (2023) optogenetic propagation atlas, OSF `e2syt`,
archive SHA256 `d6e7b3d93175b40b7ae17bde2182835e9c2144388142c522ee9be3832f6ce836`.

**Coverage:** 3,371 valid stimulation events, 110 animals, 259 stimulated
targets, 305 recorded neurons, 237,639 long-form downstream response rows
(40,341 target–neuron pairs). These are the Phase 2 counts after the same
quality filters; they are not a new biological experiment.

**Question:** can Randi stimulation data support better response modelling using
temporal shape, repeated-event averaging or stimulus context?

**Artifacts:** `randi_trial_table_phase3.csv.gz` (regenerated by the script;
untracked because it is large), `randi_reliability_by_target.csv`,
`randi_repeated_average.csv`, `randi_context_models.csv`,
`randi_phase3_summary.json`.

> This is prediction of an **observed intervention response**. It is not
> evidence that a new intervention will work, and it is not a causal transfer
> result. All virtual perturbations remain
> **MODEL-DEPENDENT VIRTUAL PERTURBATION — NOT CAUSALLY VALIDATED.**

## 1. Targets audited

The Phase 2 target was the signed peak deviation from a pre-stimulus median in a
12-frame post window. Phase 3 adds:

| Target | Definition |
|---|---|
| `response` | signed value at maximum absolute excursion |
| `response_mean` | mean post-stimulus deviation over 12 frames |
| `response_integral` | sum of post-stimulus deviations |
| temporal profile | 12-frame per-neuron post-stimulus vector |
| sign | sign of the peak response |
| `response_z` | absolute peak divided by pre-stimulus MAD noise |

The response profile keeps `post_start=1`, `post_frames=12`, `pre_frames=8`.
The stimulated neuron's own trace is excluded from targets. Missing values are
skipped, never imputed as a response.

## 2. Repeatability does not improve with the target

| Target | Repeated target groups | Event pairs | Median pairwise r | Mean r | Fraction positive | IQR |
|---|---:|---:|---:|---:|---:|---|
| `response` | 580 | 925 | 0.0900 | 0.0847 | 0.632 | [-0.126, 0.297] |
| `response_mean` | 580 | 925 | 0.0921 | 0.0817 | 0.626 | [-0.116, 0.261] |
| `response_integral` | 580 | 925 | 0.0921 | 0.0817 | 0.626 | [-0.116, 0.261] |

The mean and integral are linear rescalings of one another, so their correlations
are identical by construction. Changing from peak to mean/integral does **not**
rescue repeatability: all three sit near r ≈ 0.09. A target with a reliability of
0.09 supports only weak single-trial prediction, regardless of model class.

### Temporal shape

For 315 animal–target groups with repeated stimulations (564 event pairs), the
full 12-frame profile was compared across common neurons:

| Shape statistic | n | Median | IQR |
|---|---:|---:|---|
| Per-neuron temporal profile r | 30,220 | 0.0479 | [-0.455, 0.528] |
| Population mean time-course r | 564 | 0.1261 | [-0.457, 0.614] |
| Amplitude-vector r | 564 | 0.0852 | [-0.129, 0.270] |
| Sign agreement | 564 | 0.5179 | [0.463, 0.571] |

The population time course is slightly more repeatable than single-neuron
profiles, but the median is still only 0.126 and the IQR crosses zero. Sign
agreement is at chance. **Temporal shape is not a reliable target** in this
aggregation.

## 3. Repeated-event averaging does not help

Event-held-out split (20% of events), same rows for every model. Predictions use
training events only; the held-out event is never included in its own average.

| Model | MAE (`response`) | MAE (`response_mean`) | MAE (`response_integral`) |
|---|---:|---:|---:|
| Global training mean | **5.9008** | **2.8510** | **34.2115** |
| Stimulated-target mean | 5.9494 | 2.9061 | 34.8730 |
| Animal mean | 5.9126 | 2.8727 | 34.4725 |
| Animal × target mean | 5.9695 | 2.9318 | 35.1821 |
| Animal × target × neuron mean (pair) | 6.3238 | 3.2021 | 38.4254 |

Every repeated-average model is **worse** than the global training mean. The
pair-specific average, which is closest to "average the repeated responses",
is the worst. The 95% event-cluster bootstrap intervals are wide (e.g. global
MAE [5.29, 6.81]; pair [5.70, 7.29]) and overlap, but there is no evidence of
improvement. The reason is visible in the reliability table: repeated responses
to the same target are not similar enough for their average to beat a global
prior.

## 4. Stimulus context: scale, not typical response

A one-hot target/neuron ridge with pre-stimulus activity was compared with the
same model plus pre-stimulus SD, time since the previous stimulation, and whether
the previous target was the same. Absolute event order/session index was
deliberately excluded because it can act as an animal identifier and inflate
held-out-event performance.

| Target | Model | MAE | RMSE | R² | Pearson |
|---|---|---:|---:|---:|---:|
| `response` | one-hot + pre | 5.9967 | 60.78 | 0.0061 | 0.083 |
| `response` | + context | **5.8900** | **49.91** | **0.3297** | **0.841** |
| `response_mean` | one-hot + pre | 2.9589 | 40.81 | 0.0134 | 0.133 |
| `response_mean` | + context | **2.9027** | **32.85** | **0.3608** | **0.890** |
| `response_integral` | one-hot + pre | 35.507 | 489.72 | 0.0134 | 0.133 |
| `response_integral` | + context | **34.832** | **394.18** | **0.3608** | **0.890** |

The MAE improvement is only **1.8%** (5.9967 → 5.8900), and the event-bootstrap
CI for MAE overlaps broadly (one-hot [5.40, 6.89], context [5.35, 6.65]). The
large RMSE/R²/Pearson change is driven by a small number of very large responses:
pre-stimulus SD predicts response **scale/outliers**, not the typical response.
Reporting only Pearson 0.84 would be misleading; MAE and reliability say the
typical single-trial response is still poorly predicted.

## 5. What improved and what did not

| Question | Result | Verdict |
|---|---|---|
| Better target (mean/integral) | reliability r ≈ 0.09, same as peak | No |
| Temporal shape | median per-neuron r 0.048, population 0.126 | No |
| Repeated-event averaging | worse than global mean for every target | No |
| Stimulus context | 1.8% MAE improvement, CI overlaps; large RMSE gain from scale | Weak/inconclusive |
| Held-out targets | Phase 2 negative result retained | No |
| Held-out animals | Phase 2 negative result retained | No |

## 6. Interpretation and limits

Randi's data are experimentally measured, but the response to a repeated
stimulation of the same target is only weakly repeatable. That is a property of
the preparation/measurement and the chosen response window, not a failure of a
particular regressor. A model cannot reliably predict a single-trial response
that the same animal does not reproduce.

The context result is a warning about metrics: R² and Pearson can be dominated by
outliers, while MAE and reliability remain weak. A useful response model must
report both and must be tested on genuinely held-out interventions, not only
held-out events from the same targets.

**No result here supports neuron-specific control of a behavioural transition.**
Predicting an observed optogenetic response is not the same as predicting the
effect of a new intervention, and neither is a causal transfer result.

## 7. Reproduction

```powershell
python scripts/phase3_randi_analysis.py
```

The script rebuilds the 237,639-row table from the local OSF export, computes
reliability, repeated-average benchmarks, context models and temporal-shape
reliability, and writes the tables above. It does not download or modify the
Randi archive.
