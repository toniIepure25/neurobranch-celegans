# Gap closure matrix

**Status:** implementation plan, 2026-11-11. This is not evidence that any gap is closed. Each row
has a gate; a row becomes "closed" only when its artifact exists and passes the gate.

## 1. Why public reanalysis cannot close the main gaps

| Source | What it provides | Why it is not enough |
|---|---|---|
| Kato 2015 (`doi:10.1016/j.cell.2015.09.034`) | 5 wild-type worms, 8 states | Behaviour labels are derived from AVA/SMD/RIB; they are not independent. The recordings have already been reused. |
| Baskoylu & Flavell 2026 (`doi:10.5061/dryad.w9ghx3g4v`) | 27 freely moving animals, 43,200 frames, 1,162 reversal events, CC0 | Independent binary reversal, but **0/27** animals contain all 11 neurons of the Tier-3 readout; only **8/27** contain the full 6-neuron reverse panel. It is not a sixth BunDLe-Net worm. It has already been analysed and did not show a robust incremental neural signal. |
| Atanas / Worm Wide Web (30 JSON recordings) | whole-brain calcium recordings used by the premotor release | **0/30** recordings contain all 11 readout neurons; only **3/30** contain the full reverse panel. The exact readout cannot be extended to 30. |
| Randi 2023 (`doi:10.1038/s41586-023-06683-4`) | 110 animals, 3,371 valid stimulation events | No behavioural labels; not a matched behavioural intervention. It can test response prediction, not `do()` on behaviour. |
| Kramer 2026 (`doi:10.1038/s41593-026-02257-5`) | turning/behaviour cohort | Different preparation and endpoint; no shared BunDLe-Net embedding. |
| BunDLe-Net release | 5 consistent 3-D embeddings | No sixth embedding is public. A resampled or re-embedded animal is not the same held-out worm. |

**Consequence:** the bottleneck is data acquisition and specification, not another model.

## 3. Execution order

```text
G0 specification
  ├─ G1 sixth worm ─────┐
  ├─ G2 annotations ────┼─ G5 digital-twin readiness
  └─ G3 intervention ───┘
G4 BCI/MeDIL: separate lane, only if G0 selects it.
```

G1 and G2 can run in parallel. G3 depends on G0 (target biology) and on a lab protocol, not on G1.
G5 is not a work package; it is a claim that becomes available only after the others.

## 4. Definition of done

A row is **closed** only when:

1. the artifact exists and has a SHA256/manifest;
2. its validator passes;
3. a report is generated by frozen code;
4. the result is added to the claim ledger without stronger wording than the design supports;
5. a negative result is reported, not hidden.

Until then the UI must say **blocked on data** or **not implemented**, never "validated".
